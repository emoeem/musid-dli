## Current API boundaries

- musid-dli has no dependency on VoiceFox, lx-core, Ratatui, Crossterm or libmpv.
- The player remains VoiceFox lx-player + libmpv2. musid-dli returns StreamInfo only.
- LocalLibraryProvider and ContainerFormatHandler are separate from online MusicProvider traits.
- Download code remains in VoiceFox; no incomplete download feature flag is exposed.
- LX Music JavaScript sources are a required compatibility item, not yet migrated.
