## 3. Scan-failure semantics detail (L8, the sharpest behavioral divergence)

voicefox: one broken file never blocks the library; it lands in `scan_failures()` and the UI's "corrupt files" page (`scanner.rs:216-222`, `mod.rs:467-470`; forced rescan of corrupt files tested `mod.rs:1045-1076`).
musid-dli: `FilesystemLibrary::scan` is `scan_audio_files(...)?.iter().map(read_track).collect::<Result<Vec<_>>>()` (`src/local.rs:43-56`); `read_metadata` errors are `Error::Provider` (`src/local.rs:164-168`), so the first damaged or non-audio-magic file aborts the scan and no tracks are returned. A host that needs voicefox semantics must wrap per-file reads itself, or `scan` needs a failure-tolerant mode.

## 4. Container handler contract (musid-dli structure voicefox does not have)

`ContainerFormatHandler` (`src/formats.rs:39-52`): `id`, `extensions`, `inspect`, `extract_audio_to`, default `inspect_tracks`. Implementations: `CueHandler` (`formats_cue.rs:44-79`, `local` feature) and `NcmHandler` (`formats_ncm.rs:73-110`, `ncm` feature). Semantics recorded in the ask's scope: CUE splitting is metadata-only upstream and here (`formats.rs:15-19` doc, `formats_cue.rs:37-43`); `extract_audio_to` streams the referenced audio verbatim, callers seek by `start_ms`. NCM streams the decrypted plain MP3/FLAC/M4A/WAV/Ogg audio (`formats_ncm.rs:93-109`).
CUE audio format is derived from the file extension (`audio_format_for`, `formats_cue.rs:124-140`); NCM format is sniffed from the first 16 decrypted bytes via `NcmHeaders::effective_format` (`formats_ncm.rs:149-163`).

## 6. Notes on honesty of upstream claims

- voicefox `FileFingerprint` is filesystem metadata (size + mtime nanos), not an audio-content hash (`scanner.rs:43-46` doc); "fingerprint parity" therefore means copying this cheap mechanism, no hashing needed.
- voicefox watcher requires `force` rescans because directory mtime does not reflect in-place edits (`scanner.rs:68-73`, `mod.rs:592-596`); any port must keep that subtlety.
- musid-dli `formats_cue.rs` intentionally errors on undecodable encodings (`formats_cue.rs:640-653` test) where voicefox also errors after GB18030 fails (`scanner.rs:293-301`); behavior matches.
- voicefox legacy CUE path skips tracks without a parsed INDEX 01 start (`scanner.rs:491`) and ignores TRACK blocks before FILE (`scanner.rs:492-496`); musid test `formats_cue.rs:768-802` mirrors "legacy path drops tracks with invalid index times" and the sibling test at `formats_cue.rs:816` covers "tracks without INDEX 01 are skipped or rejected"; both keep the standards-compliant path strict (`formats_cue.rs:754-767`).
